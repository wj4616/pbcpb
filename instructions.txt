Playbook Creator Playbook — Quick Start

This project contains a meta-playbook for creating domain-specific playbooks.
The playbook creator itself (playbook-creator-playbook.json) is a 17-phase
workflow that guides you through building a structured, validated playbook
for any domain.

USAGE:
  1. Load playbook-creator-playbook.json as context for an AI planning session.
  2. Follow phases 0-16 sequentially, passing each gate before advancing.
  3. Each phase has a compilation block that configures the agent's mindset,
     context, and objectives.
  4. Output: a domain-specific playbook JSON matching templates/output-schema.json.

VALIDATION:
  python3 scripts/validate_playbook.py playbook-creator-playbook.json   # structural
  python3 scripts/validate_semantic.py playbook-creator-playbook.json   # semantic
  python3 -m pytest scripts/compilation/ -q                             # unit tests

ROLES:
  Coordinator  — Phase gates, tracking, status updates
  Stakeholder  — Scope, constraints, success criteria, approval
  Researcher   — Domain research, best practices, competitive analysis
  Architect    — Phase structure, task granularity, dependency mapping
  Builder      — Task writing, JSON assembly, validation, fixes
  Auditor      — Quality review, gap analysis, stress testing

For single-agent use: one person/AI fills all roles, switching mindset per phase.
The compilation block in each phase tells the agent which role to adopt.
